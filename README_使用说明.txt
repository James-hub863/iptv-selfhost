苏州联通 · 精选 IPTV 播放列表
================================

【文件说明】
- 苏州联通_精选IPTV.m3u  主文件，36 个频道，含主+备双线路，共 73 条
- gen_m3u.py / probe3.py  生成脚本（需 Python3 + 两份源 txt）

【频道构成】
- 央视频道 (18 套)：CCTV1 ~ CCTV17 全系列
- 江浙沪卫视 (13 套)：东方/江苏/浙江/湖南/北京/深圳/广东/山东/安徽/东南/海峡/厦门卫视 + 上海第一财经
- 苏州本地 (1 套)：苏州 4K（kan0512 官方直播源）
- 少儿频道 (5 套)：金鹰卡通/卡酷少儿/优漫卡通/浙江少儿

【选源策略（对苏州联通最友好）】
- 优先江苏本省 IP（221.226 / 218.1 等网段）
- 其次联通骨干网段（112.x / 123.x / 221.7 等）
- 再次电信及其他公开 CDN
- 每个频道保留 1 主 1 备两条线路

【云端探测说明】
脚本在云服务器上运行时，绝大多数源返回 HTTP 403——
这是正常现象：这些源大多做了 IP 白名单/地区限制，
只放行真实家庭宽带 IP。所以 403 ≠ 你家用不了。
请在苏州联通宽带环境下，用播放器实际验证。

【使用方法】
- VLC：媒体 → 打开网络串流 → 选本 m3u 文件
- TiviMate / IPTV Smarters（Android TV）：添加播放列表 → 本地文件
- TVBox / 影视仓：配置源里填本文件所在 http 地址
- 播放器里建议开启「自动切换线路/失败时切备用」

【更新】
免费源寿命几天到几周不等，建议每周重新生成一次：
  1) 下载最新的 iptv4.txt / live.txt 两个源
  2) 运行 python3 probe3.py 重新生成 m3u
  3) 或直接替换为上游订阅链接（见下方）
