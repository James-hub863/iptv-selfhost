【苏州移动 IPTV M3U 使用说明】
============================================

一、文件说明
------------
苏州移动IPTV.m3u —— 主播放列表，可直接导入播放器

共包含频道分组：
  📺 说明       使用说明条目
  🏙️ 苏州本地   苏州新闻/社会/文化/电影/生活 + 苏州4K（主备3线）
  🇨🇳 央视·高清  CCTV-1 ~ CCTV-17 + 高尔夫网球（江苏移动内网源）
  🇨🇳 央视·4K   CCTV-4K 超高清
  🛰️ 卫视        江苏/东方/浙江/湖南/北京/广东等15个卫视
  🏠 江苏本地    江苏城市/教育/体育 + 南京教科/生活/娱乐
  🧒 教育少儿    CETV1-4、卡酷、金鹰卡通、嘉佳卡通
  🌍 国际        CGTN
  📡 组播·需UDPXY  CCTV1组播示例（需路由器开启UDPXY）
  🔗 聚合订阅    APTV江苏移动 + suxuang移动IPTV精选

二、适用网络
------------
✅ 苏州移动宽带（江苏移动内网源 183.207.248.71 在移动网内最佳）
⚠️ 电信/联通访问江苏移动内网源可能失败或部分可用
⚠️ 组播源(udp://)必须路由器开启UDPXY转换为http才能播

三、播放器导入方式
------------------
• VLC：媒体 → 打开文件 → 选 苏州移动IPTV.m3u
• TiviMate / IPTV Smarters：添加播放列表 → 本地文件
• TVBox / 影视仓：把文件放http空间，填配置地址
• APTV：直接用内置订阅 https://itv.aptv.app/china-iptv/jsyd.m3u

四、开启UDPXY（组播转单播）
---------------------------
1. 光猫改桥接，路由器拨号（OpenWrt/老毛子/Padavan）
2. 开启 UDPXY 服务，默认端口 8080
3. 把文件里 udp://239.39.3.119:14022
   替换为 http://192.168.1.1:8080/udp/239.39.3.119:14022
4. 江苏移动组播段：239.39.0.0/16  端口常见 8000/14022/9614

五、源的技术来源
----------------
• 苏州台官方源：liveshowbak2.kan0512.com、live-auth.51kandianshi.com
• 江苏移动内网单播：183.207.248.71（JSGD=江苏移动，SMS=单播）
• 南京台：live.nbs.cn
• 聚合备份：itv.aptv.app/china-iptv/jsyd.m3u、suxuang/myIPTV

六、稳定性提示
--------------
• 内网单播源在移动宽带下基本秒开、长期稳定
• 若某频道 403/404，多半是鉴权过期，换备用线路即可
• 想全自动维护，可把这份列表纳入上一轮搭的 GitHub Actions 测活流水线
