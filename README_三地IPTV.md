## 📖 使用方法

1. **VLC**：媒体 → 打开文件 → 选对应 `.m3u` 文件
2. **TiviMate / IPTV Smarters**：添加播放列表 → 本地文件 → 选对应文件
3. **TVBox / 影视仓**：把文件传到 HTTP 空间，填配置地址
4. **手机端**：VLC for Android/iOS 直接打开文件

## ⚠️ 重要提醒

- **运营商匹配**：江西移动源在电信/联通下可能限速或 403，建议对应运营商宽带使用
- **宁都台 Key 变化**：趣看平台的 auth_key 是时效性签名，过期后需重新获取
- **组播源需转单播**：如 `rtp://239.x.x.x:5140` 这种需路由器开 UDPXY 才能播
- **仅供个人观看**：所有源均收集自公开资源，请勿二次分发与商用
